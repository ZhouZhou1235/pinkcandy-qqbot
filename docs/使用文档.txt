安装python环境
安装QQ
安装napcat

项目根目录下：
[windows]
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
[linux]
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

创建 config.json 放到根目录

启动
[windows]
点击 launcher.bat
venv\Scripts\activate
python main.py
[linux]
napcat
source venv/bin/activate
python3 main.py
